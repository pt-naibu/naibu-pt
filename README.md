# 内部障害理学療法（○×200問）— GitHub Pages 公開手順

このフォルダをそのままGitHubに置くと、学生がスマホで開けるアプリになります。一度開けば、通信がない場所でも使えます（オフライン対応）。

## フォルダの中身

| ファイル | 役割 |
| --- | --- |
| index.html | アプリ本体 |
| data.json | 問題データ（200問）。問題の修正・追加はこのファイルだけ |
| sw.js | オフライン用の仕組み。触らなくてよい |
| manifest.webmanifest | ホーム画面に追加したときの名前とアイコン |
| icons/ | アイコン画像 |
| .nojekyll | GitHub Pages用の設定ファイル（空ファイル）。削除しない |

## 公開手順（初回だけ・10分）

1. https://github.com でアカウントを作る（無料）。
2. 右上の「+」→「New repository」。
   - Repository name: `naibu-pt`（好きな名前でよい。半角英数字）
   - Public を選ぶ
   - 「Add a README file」はチェックしない
   - 「Create repository」
3. 「uploading an existing file」のリンクを押し、このフォルダの中身（index.html、data.json、sw.js、manifest.webmanifest、.nojekyll、iconsフォルダ）をまとめてドラッグ&ドロップ。下の「Commit changes」を押す。
   - iconsフォルダごとドラッグすれば、中の画像も一緒に上がります。
   - `.nojekyll` は名前が「.」で始まるため、パソコンで非表示になっていることがあります。見えないときは、アップロード後にGitHub上で「Add file」→「Create new file」、ファイル名に `.nojekyll` と入れて中身は空のまま「Commit」で作れます。
4. リポジトリの「Settings」→ 左メニュー「Pages」。
   - Build and deployment の Source: 「Deploy from a branch」
   - Branch: 「main」、フォルダ「/ (root)」→「Save」
5. 1〜2分待って同じ画面を開き直すと、上部に公開URLが出ます。
   `https://（ユーザー名）.github.io/naibu-pt/`
6. スマホでそのURLを開いて動作を確認する。

## 学生への配布

- URLをLMSや掲示、QRコードで配る。アカウント登録もアプリのインストールも不要です。
- ホーム画面に追加すると、アプリのように起動できます。
  - iPhone（Safari）: 画面下の「共有」→「ホーム画面に追加」
  - Android（Chrome）: 右上のメニュー→「ホーム画面に追加」または「アプリをインストール」
- 一度開けば、次からは通信がなくても使えます。ホーム画面に「このアプリは端末に保存されました」と出ていれば保存済みです。
- 記録（正答率など）は各自の端末の中にだけ残り、教員には送られません。学生がブラウザのデータを消すと記録も消えます。

## 問題の修正・追加（運用）

1. 直したい内容をClaudeに伝え、新しい `data.json` を受け取る。
2. GitHubのリポジトリで `data.json` を開き、右上の鉛筆マーク（Edit）→中身を貼り替えて「Commit changes」。または「Add file」→「Upload files」で同じ名前のファイルを上書きアップロード。
3. 数分で公開版が更新されます。学生は、次に通信のある場所でアプリを開いたときに自動で新しい問題になります（オフラインのときは保存済みの古い版が動き、通信が戻れば入れ替わります）。
4. `sw.js` や `index.html` は変えなくてよい。アプリの見た目や機能を変えるときは、Claudeが新しい `index.html` を作るので、同じ方法で上書きする。

## 注意

- 公開URLは誰でも開けます（学内限定にはできません）。問題と解説は一般的な学習内容なので問題ありませんが、個人情報は入れないでください。
- フォントはインターネットから読み込みます。通信がない場所では端末のフォントで表示されますが、動作は変わりません。
- 同じ方法で、他のアプリ（100本ノック、在宅編）も公開できます。
